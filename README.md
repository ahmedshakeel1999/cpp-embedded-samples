# cpp-embedded-samples
C++ embedded systems code samples (motor control, sensor integration, CAN communication, state machines

## Overview
Code samples demonstrating embedded C++ patterns 
from my work with automotive ECUs and autonomous systems.

## Contents
- motor_controller/ — PWM-based motor control with OOP
- ultrasonic_sensor/ — Sensor abstraction layer
- can_handler/ — CAN-Bus message processing
- state_machine/ — Robot navigation state machine

## Technologies
Embedded Linux, Arduino/AVR, ROS, CAN-Bus
